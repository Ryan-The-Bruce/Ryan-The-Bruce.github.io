PID Oven

Highlights · early build
  • Installed custom controls on a toaster oven, adding insulation and thermal safety features
  • Tuned temperature control with a high-delay PID algorithm, achieving ~0.1 °C control
  • Added dual temperature sensors for better accuracy
  • Programmed macros for slow temperature ramping to minimize thermal gradients during annealing
Highlights · upgraded / finished
  • Added a touchscreen controller over USB-C, so a generic cable can extend or shorten the reach
  • Built in a safety mechanism: if the screen disconnects, all heaters shut off and the fan runs at full speed
  • Custom touchscreen interface with simple buttons that limit access to settings, reducing accidental input and unwanted changes
  • Pre-programmed annealing profiles for PET-CF and PPS-CF, plus drying profiles for a wide range of filaments
